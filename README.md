# 🔐 Private Key Manager

A lightweight, no-nonsense solution for managing private keys in local development environments.

> ⚠️ No out-of-the-box solutions, no fancy dependencies — just clean, simple logic you control.

---

## 🚀 Features

- ✅ **Secure Local Key Handling**  
  Manage your private keys safely using `.env` files.

- 🧠 **Simple by Design**  
  No third-party services or cloud storage — everything runs locally.

- 📦 **No Hardcoding**  
  Keeps your keys out of the source code for better security and modularity.

- ⚙️ **Easy Integration**  
  Drop into any Node.js project and you're ready to go.
